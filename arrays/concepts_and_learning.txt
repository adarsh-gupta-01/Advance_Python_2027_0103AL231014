Learning:
1. Learned how to solve in O(n) time and O(1) extra space.
2. Understood why negatives and numbers > n are irrelevant.

Core Insight:
If number x exists in array and 1 <= x <= n,
then mark index (x - 1) as negative.

First index that remains positive → missing number.

class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:

        # Submit kar diya hai but abhi ise acche se samjhke khud se krna hai 
        
        n = len(nums)

        # Step 1: Replace negatives and >n numbers
        for i in range(n):
            if nums[i] <= 0 or nums[i] > n:
                nums[i] = n + 1

        # Step 2: Mark numbers as negative
        for num in nums:
            val = abs(num)
            if val <= n:
                nums[val - 1] = -abs(nums[val - 1])

        # Step 3: Find first positive index
        for i in range(n):
            if nums[i] > 0:
                return i + 1

        return n + 1
