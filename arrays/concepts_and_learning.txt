Learning:
1. Reversal Algorithm seekha array rotation ke liye.
2. Samjha ki ye kyun zaroori hai:
       k = k % len(nums)
   Ye un cases ko handle karta hai jab k > n ho.

Concept:
Pura array reverse karo →
Pehle k elements reverse karo →
Baaki ke elements reverse karo →
Final array right-rotate ho jata hai k steps se.

10. Merge Sorted Array
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Concept:
- Dono arrays ke sabse bade elements compare karo.
- Jo bada ho use end mein (k index pe) rakho.
- Pointers ko accordingly move karo.
- Tab tak continue karo jab tak nums2 fully merge na ho jaye.

Learning:
1. Backward two-pointer technique seekhi.
2. Samjha ki end se kyun fill karna zaroori hai.
3. Teen pointers use karna practice kiya:
       i → nums1 ka last valid element
       j → nums2 ka last element
       k → nums1 ki last position (total size)
4. Seekha ki extra space ke bina in-place kaise merge karte hain.
5. Samjha ki ye check karna kyun important hai:
       i >= 0
   Index error avoid karne ke liye.
6. Loop ke andar conditional decision making强 hui.
7. Soch improve hui ki useful values ko overwrite karne se kaise bachein.

16. Check if Two Arrays are Equal or Not
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Learning:
1. Seekha ki frequency hashmap use karke arrays ko kaise compare karte hain.
2. Samjha ki array lengths ko pehle check karna kyun important hai.
3. dictionary.get(key, default) ka use practice kiya.
4. Frequency counting technique strong hui.
5. Seekha ki second array validate karte waqt counts ko kaise decrement karte hain.
6. Samjha ki ye check karna kyun zaroori hai:
       if count[num] < 0
   Extra occurrences detect karne ke liye.
7. O(n) comparison ki understanding improve hui instead of sorting (O(n log n)).

Concept:
- Agar lengths different hain → arrays equal nahi ho sakte.
- First array ke elements ki frequencies count karo.
- Second array traverse karte waqt frequency decrease karo.
- Agar koi mismatch ho → False return karo.
